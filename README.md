## ĐỒ ÁN MÔN HỌC

- **Tên đề tài:** WEBSITE BÁN HÀNG
- **Tên sản phẩm:** Vinmark

**Vinmark** là website bán hàng trực tuyến, hỗ trợ khách hàng tìm kiếm sản phẩm, quản lý giỏ hàng và đặt hàng. Hệ thống cung cấp khu vực quản trị để quản lý sản phẩm, danh mục, đơn hàng, người dùng và theo dõi hoạt động bán hàng.

### Chức năng chính

**Phía khách hàng:**

- Đăng ký, đăng nhập, khôi phục mật khẩu và quản lý tài khoản.
- Xem danh sách, tìm kiếm, lọc và xem chi tiết sản phẩm.
- Quản lý giỏ hàng và danh sách sản phẩm yêu thích.
- Quản lý địa chỉ giao hàng, đặt hàng và xem lịch sử đơn hàng.
- Đánh giá sản phẩm, gửi liên hệ và sử dụng chatbot hỗ trợ.

**Phía quản trị:**

- Xem thống kê hoạt động bán hàng.
- Quản lý sản phẩm và danh mục.
- Quản lý đơn hàng và cập nhật trạng thái xử lý.
- Quản lý người dùng và phân quyền truy cập.
- Quản lý thông báo và phản hồi liên hệ của khách hàng.

### Công nghệ sử dụng

| Thành phần | Công nghệ |
| --- | --- |
| Backend | PHP 8.2 trở lên, Laravel 12 |
| Cơ sở dữ liệu | MySQL |
| Giao diện | Laravel Blade, Bootstrap, jQuery |
| Công cụ xây dựng tài nguyên | Vite |
